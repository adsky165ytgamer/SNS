# NoticeFlow Sender v1.1.2 Beta Material 3

This is a new, non-destructive official Beta release for package `app.sender`. Previous Alpha releases remain available unchanged.

## What is included

The Sender retains real Firebase Email/Password authentication, password recovery, authenticated live Receiver discovery, searchable target selection, live-list loading feedback, notice dispatch, persistent local delivery history, selected navigation feedback, and safe spacing for display cutouts and navigation bars. No device names or delivery results are fabricated.

## Verification

The Sender package is `app.sender`, version code `5`, version `1.1.2-beta-material3`, with Android 8.0+ support. The APK verifies using APK Signature Scheme v2 and the official Sender certificate fingerprint `D2:E7:74:1B:AB:01:19:63:69:DE:50:4B:D1:06:9A:88:1C:AC:D0:50`.
