# NoticeFlow Sender v1.1.0 Alpha — stable UI restore

This release restores the original stable Sender interface. The previous mobile redesign has been removed; the proven account → delivery target → notice workflow is back.

Only functional fixes remain: the Sender refreshes the Firebase Email/Password session before loading devices, shows explicit loading/authentication/backend/empty states, keeps the live Receiver cards and notice composer usable, preserves punch-hole/navigation-bar insets, and corrects authentication guidance to reference the Sender Email/Password account.

The backend and Receiver application are unchanged. The build is package `app.sender`, version `1.1.0-alpha`, version code `3`. NoticeFlow remains proprietary and is not open source. Creator: **ad_vibe_dev**.
